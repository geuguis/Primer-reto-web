### Primer-reto-web

El objetivo principal de esta actividad individual es demostrar todo lo aprendido en la asignatura de LDM hasta la fecha. Como subobjetivos están la capacidad de entender las necesidades de un caso real y plantear un boceto técnico de un documento web, usar los estándares HTML5 y CSS3 de forma óptima y siguiendo una buenas prácticas desarrolladas en clase.
